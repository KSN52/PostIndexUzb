# OSM парсер почтовых индексов Узбекистана

## Назначение
Простой парсер OSM (XML) для извлечения почтовых индексов городов Узбекистана с
агрегацией по названию населенного пункта.

## Структура каталогов
- `Main py` — основной CLI-скрипт парсера.
- `README.MD` — описание проекта, архитектура и правила работы.

## Архитектура
1. Потоковый разбор OSM через `iterparse` без загрузки файла целиком.
2. Извлечение тегов и фильтрация по стране (по тегам страны или по умолчанию).
3. Источники индексов:
   - `place=*` (города/поселения);
   - административные границы (`boundary=administrative`);
   - адреса с `addr:city` и `addr:postcode`.
4. Аггрегация индексов по городу и сохранение в CSV/JSON.

## Использование
- CSV по умолчанию:
  - `python "Main py" --input uzbekistan.osm --output uz_postcodes.csv --stats`
- JSON:
  - `python "Main py" --input uzbekistan.osm --output uz_postcodes.json --format json`
- Отключить адресный источник:
  - `python "Main py" --input uzbekistan.osm --no-addresses`

## Зависимости
- Внешние зависимости отсутствуют.
- Используется только стандартная библиотека Python 3.

## Правила работы с кодовой базой
- Перед рефакторингом анализировать зависимости и обратную совместимость.
- Новые решения не должны снижать функциональность, упрощения достигаются
  организацией кода, архитектуры и шаблонов.
- Изменения в архитектуре и правилах отражать в `README.MD`.
- Для больших OSM-файлов использовать только потоковый разбор.
